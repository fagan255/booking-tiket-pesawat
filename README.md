# ✈️ Booking Tiket Pesawat

Project LSP Sistem Booking Tiket Pesawat.

## 📋 Fitur

- Login Admin
- Dashboard
- Data Pelanggan
- Data Penerbangan
- Pemesanan Tiket
- Pembayaran
- Laporan

## 🛠 Teknologi

- PHP
- MySQL
- HTML
- CSS
- JavaScript

## 🚀 Cara Menjalankan

1. Clone repository
2. Import database ke phpMyAdmin
3. Jalankan Apache dan MySQL
4. Buka project melalui browser
